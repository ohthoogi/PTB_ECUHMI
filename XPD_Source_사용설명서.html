    XPD Source 사용설명서

    XPD → 소스 만들기 · 소스 수정 후 → XPD 만들기

    01. XPD → 소스 만들기

    PowerShell에서 작업 폴더로 이동합니다.

    Set-Location 'D:/Program/AppCodex/ETC/xpd-source/GitFolder'

    기존 sample-source를 XPD 내용으로 갱신

    python ./xpd.py sync "D:/경로/프로젝트.xpd" ./sample-source

    D:/경로/프로젝트.xpd를 소스로 분리할 실제 XPD 경로로 바꾸세요.

    기존 소스는 sample-source/build/sync-backups/에 백업한 뒤 선택한 XPD 내용으로 교체합니다. 아직 XPD로 만들지 않은 TXT 수정사항이 있다면 먼저 아래의 build를 실행하세요.

    처음 추출하여 새 폴더를 만들 때

    python ./xpd.py extract "D:/경로/프로젝트.xpd" ./sample-source

    extract는 대상 폴더가 없을 때만 사용합니다. 이미 sample-source가 있으면 위의 sync를 사용하세요.

    02. 소스 수정 후 → XPD 만들기

    sample-source/scripts/*.txt의 스크립트 본문 또는 sample-source/screens/*.json의 기존 표시 문구를 수정하고 저장합니다. 파일명과 JSON 키는 유지하세요.

    같은 작업 폴더에서 검사 후 XPD를 생성합니다.

    Set-Location 'D:/Program/AppCodex/ETC/xpd-source/GitFolder'

python ./xpd.py check ./sample-source
python ./xpd.py build ./sample-source ./sample-source/build/edited-v1.xpd

    생성 파일: GitFolder/sample-source/build/edited-v1.xpd

    같은 이름의 출력 파일이 있으면 edited-v2.xpd처럼 새 이름을 지정하세요. 생성된 XPD는 XP-Builder에서 열어 데이터 검사와 변경한 동작을 확인합니다.
